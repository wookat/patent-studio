# patent_docx —— CN 发明专利申请文件（Word）通用生成工具

内容与排版分离：正文写在 `content.md`（Markdown），本工具负责按 CNIPA
发明专利格式装配成 docx；PDF 用 LibreOffice 命令行导出。

## 特性

- 五部分（说明书摘要 / 摘要附图 / 权利要求书 / 说明书 / 说明书附图）各起新页
- 权利要求书与说明书独立页码（页脚 PAGE 域）
- 说明书段号 `[0001]` 自动连续编号（content.md 中不写段号，空行分段即可）
- 行内下标记号 `_x` / `_{...}` / `_[...]` 渲染为 Word 真下标
- `$$...$$` 独立公式渲染为 OMML 原生 Word 公式对象（Word 中可双击编辑）
- A4 版式，正文宋体小四两端对齐，标题黑体；支持 PNG 与 EMF 附图
- 内置校验：摘要字数上限（默认 300）、构建后打印权项数/段落数

## content.md 格式约定

```markdown
# 发明名称（全文唯一一级标题）

## 摘要

摘要正文（一段，≤300 字）。

## 权利要求书

1. 一种……方法，其特征在于，包括：
步骤一……；
$$g_t = clip(…, 0, 1)$$
步骤二……。

2. 根据权利要求1所述的方法，其特征在于，……。

## 说明书

### 技术领域

[段落正文，空行分段，自动编号 [0001]…]

$$W_t = W_{t-1}·(1+b_t·r_t)$$ （3）

#### 实施例一（四级标题为小节标题）
```

- 权利要求书内：空行分隔的块 = 一项权利要求；块内每行一个段；
  `$$公式$$` 独立行 = 权项内独立成行公式。
- 说明书内：`###` = 章节标题，`####` = 小节标题，普通段落块 = 一个编号段，
  `$$公式$$ （编号）` = 独立成行编号公式（编号可空）。
- 说明书表格：标准 Markdown 表格语法（`| 列1 | 列2 |`，`---` 分隔行可选），
  渲染为全框细黑线居中表格（首行表头加粗，表内支持下标记号）；
  表格本身占用一个空段号、表题写成其前的普通段落（如 `表1 xxx对比结果`），
  与已授权专利版式一致（参照 CN110033091B/CN108584592B/CN113033643B 实样）。
- 表题段、表格段号及表头行自动设置 keep-with-next，避免表题/表体分页孤行
  （逐页调研中 CN110059878B/CN112101480B/CN113128781B/CN115622047B 均存在该瑕疵）。
- 表格高级选项：表格前一行写 HTML 注释声明（各项均可选，可组合）：
  `<!-- 表格: 三线 重复表头 段号居左 列宽=20,20,30,30 表题后置=表2 参数对照表 -->`
  - `三线`：三线表样式（顶线/表头下线/底线，无竖线；参照 CN110414719B 实样）
  - `重复表头`：表格跨页时自动重复表头行（样本授权案多不重复，按需启用）
  - `段号居左`：段号纵向居中于表格左侧（授权案公告版多数派版式；默认为段号在表格上方）
  - `列宽=a,b,c`：各列宽度百分比（固定布局）
  - `表题后置=…`：表题作为表格之后的编号段（少数派版式；默认表题写在表格前）
  - 单元格写 `^^` 表示与上一行同列单元格竖向合并（参照 CN110414719B 表1 实样）
  - 表格后紧跟以 `注：` 开头的行 = 表注，渲染为表格下方 10.5pt 编号段
- 伪代码段：三反引号围栏代码块渲染为一个编号段内多行等宽体（Courier New），
  参照样本授权案伪代码直接入编号段的写法。

## 用法

新案目录下放 `content.md` 与 `figs/`，写一个约 20 行的配置脚本：

```python
import os, sys
HERE = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, "<patent_docx 所在父目录>")
from patent_docx import build_patent

build_patent({
    "content_md": os.path.join(HERE, "content.md"),
    "out": os.path.join(HERE, "申请文件-XXX.docx"),
    "figs_dir": os.path.join(HERE, "figs"),
    "abstract_figure": ("fig1.png", 14.5),          # 摘要附图（文件, 宽度cm）
    "spec_figures": [("fig1.png", 15.0), ("fig2.png", 15.0)],  # 图1..N
    # 可选："sub_except": ("tsf_guard",)  不作下标解析的字面标识符
    # 可选："abstract_limit": 300
})
```

PDF 导出：

```bash
soffice --headless --convert-to pdf 申请文件-XXX.docx
```

## 注意

- 附图应为白底黑色线条图（专利要求），建议 300dpi PNG 或 EMF 矢量
- 公式内 ASCII 竖线 `|` 会被替换为数学竖线 `∣`（LibreOffice OMML 兼容）
- 本工具只生成申请文件四书；请求书/委托书等程序性材料由代理机构环节补充

- 版式对齐授权公告版（2026-08 实测校准）：部分标题黑体四号字间全角空格；说明书首页发明名称黑体四号居中；段号 [000n] 黑体小五紧接正文；权项号后不加空格。
