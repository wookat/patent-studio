# 句式与过渡语库（千件语料矿采）

> 来源：~500+ 件 CN 授权发明（计算机域为主）逐句 n-gram 挖掘。括号内为语料频次。
> 用法：起草时按所处章节直接选用句式骨架填内容，不要自创过渡语。

## 说明书·实施方式开头（任选一族）

- `在一些实施例中，……`（354）
- `本发明实施例提供一种……`（292）
- `本申请实施例中，……`（238）
- `在一个实施例中，……`（265）
- `在本实施例中，……`（237）
- `需要说明的是，……`（286）——注解/边界声明
- `进一步地，所述……`（170）——在既述对象上补限定
- `可选地，所述……`（159）——非必要变体
- `优选地，所述……`（108）
- `示例性的，……`——大厂企业件高频（阿里云等），紧随步骤后展开细节

## 附图说明段首

- `为了更清楚地说明本申请实施例中的技术方案，下面将对实施例描述中所需要使用的附图作简单地介绍`（63+61 变体）
- `图 1 是本申请实施例提供的一种……流程示意图`——每图一句「图 N 是……示意/流程图」

## 发明内容段首/段尾

- `本发明的目的在于提供一种……`（64）／`为了解决上述技术问题，本申请实施例提供……`（41）
- 段尾效果句：`与现有技术相比，本申请实施例……`（48）／`综上所述，本……`（41）
- 完整效果段模板：`基于上述技术方案，本申请实施例中，……（复述方法），从而……，进而……，提升……。`

## 背景技术段首

- `随着……技术的发展，……已经成为……的重要组成部分`——场景引入主流写法
- 接 `在相关技术中，采用……从而获得……；但是现在的技术方案存在……的问题`——一
  句归纳缺陷即可，不必逐条枚举（语料枚举式仅 ~7%）

## 步骤层细节展开（实施方式内部）

- 步骤编号：`步骤 101，……`（企业件 10x 式）或 `步骤 1：……`（高校件数字式）
- 步后展开：`示例性的，在步骤 N 之前/之后，还可以……`
- 特征细化：`该 X 特征可以包括但不限于以下向量的至少一种：……`
- 分支变体：`在一种可能的实施方式中，可以确定……。若否，则……；若是，则……`
- 顺序免责：`上述执行顺序只是为了方便描述给出的一个示例，在实际应用中，还可以改变步骤之间的执行顺序`（企业件 boilerplate，全文复用）
- 跨权项镜像：`基于与上述方法同样的申请构思，本申请实施例中还提出……，参见图 2 所示`——
  每个独立权项在实施方式中各有一段镜像展开，逐一步骤复述并补细节（不复用引用）

## 从权句式（语料分布）

- 特征限定式（占 ~92%）：`根据权利要求 N 所述的 X，其特征在于，所述 Y 为/包括/通过……`（1048）
- 还包括式（~4%）：`根据权利要求 N 所述的 X，其特征在于，还包括：……`（45）
- 进一步明确式（<1%）：`根据权利要求 N 所述的 X，其特征在于，所述步骤进一步包括……`（2）
- 推荐句式：`根据权利要求 N 所述的方法，其中，所述 <限定对象> 具体为 <具体化>；`
  或 `根据权利要求 N 所述的方法，其中，所述 <步骤> 包括：<子步骤 a>；<子步骤 b>。`

## 效果动词频次（效果句首选）

`实现`（310）＞`解决`（181）＞`优化`（153）＞`提高`（40）＞`增强`（29）＞`保证`（26）＞`降低`（18）
组合公式：`……，从而 <实现/解决> <对象目标>，<进而> <提高/降低> <度量>。`

## 自称（语料：统一者 ~86%）

任选一族全篇一致：`本申请`（新兴企业件主流 73% 中的大头）/ `本发明` / `本公开`（外企在华件）。
混用触发 style.self_ref lint。
