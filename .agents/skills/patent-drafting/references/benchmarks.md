## 形式惯例（占比即可信度）

- 「其特征在于」：权 1 达 88% —— 缺它 lint 会提示复核
- 从属权句式：**特征限定式 95.9%**（`……，其特征在于/其中，所述 Y 为/包括……`）；还包括式 ~0.5%；进一步明确式 <1%
- 引用措辞：「根据权利要求」≈78%，「如权利要求」≈22%（推荐「根据」统一）
- 「包括」引出特征：96%；权 1 = 方法：91%；编号步骤式权 1：18%（少数派）
- 发明内容含「有益效果」段：68%；「第一/二/三方面」布局：26%
- 摘要以效果句收尾：约半数；背景尾部指明缺陷：72%（枚举式仅 7%）
- 显式「实施例一/二」编号：仅 17%；按图/步骤连续展开是主流
- 效果动词频次：实现(310)>解决(181)>优化(153)>提高(40)>增强(29)

## 自称（重点纠偏）

- 统一自称者 ~87%；混用 ~12%（122/1001，触发 style.self_ref lint）
- 全体主导自称构成：**本发明 ~76% 是主流**，本申请 ~17%，本公开 ~6%（外企在华件）
- 结论：默认用「本发明（实施例）」；目标客户是企业件风也可「本申请」，但**不可混用**

## 权 1 两种主流句式（皆可）

- **分号连排**（~82%）：`一种……方法，其特征在于，包括：特征A；基于所述特征A的特征B；……`
- **编号步骤**（~18%）：`其特征在于：步骤1：……；步骤1.1：……`——高校/院所风格，流程复杂的案子更清晰

## 权项链（可选而非必须）

- 全链 方法+装置+介质：仅 18% —— 写方法是底线，装置/设备/介质按保护策略加
- 有方法权才有设备/介质权的意义（「执行权利要求N所述方法」）

## 高频过渡语（按用途归类）——详见 phrases.md

- **引出实施细节**：在一些实施例中 / 在另一些实施例中 / 具体地 / 示例性地 / 作为一种可选的实施方式
- **退路限定**：可选地 / 优选地 / 进一步地 / 另外
- **回指**：上述 / 所述 / 基于此 / 在此基础（上）
- **举例**：例如 / 举例说明
- **澄清**（慎用频度）：需要说明的是 / 应当理解 / 本领域技术人员可以理解
- **承启**：下面结合附图 / 为使本申请的目的、技术方案和优点更加清楚 / 有鉴于此 / 为了解决……问题
