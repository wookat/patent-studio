> 角色：UX 研究员 + UI 设计师（company-os `roles/design/ux-researcher.md` / `ui-designer.md`）。
> 基线：`devin/wave5-integrated`；分支：`devin/w6-visual-audit`。只做设计探索，不改产品代码。

> 证据约定：所有截图为本人在本地实跑（`PATENT_STUDIO_AUTH=on`，mock AI，LibreOffice PDF）用 Playwright 亲自截取，目录 `docs/archive/design-system/w6-audit/shots/`，命名 `<d|m>-<light|dark>--<页面>.png`（d = 1440×900，m = 375×812 移动仿真）。竞品事实引用 `00-benchmark.md`（已有结论，不重做提取）；未直接验证的写"推断"。

## 0. 结论摘要（TL;DR）

1. **"看起来没变"是有数据原因的**：波次 5 把颜色搬进了 OKLCH token（`index.css` 原始层 `--n0..n9`）、把高度写进了 `--h-*` 变量，但**页面上可见的形态基本没动**——按钮/Tab/菜单项圆角桌面 77% / 移动 69% 是 4px（其余是 0 与 pill，6px 仅 1–3%）、字号 12–14px 占 98%、按钮高度实测桌面 15 档（15/16/20/22/24/26/28/30/32/36/38/39/42/59/76）、移动 14 档、灰色文字只有 2 阶（`--n7`/`--n9`，占文字节点 90%+）。等值迁移 = 视觉等值。见 §2。
2. **信息架构和层级问题比样式问题更大**：工作台默认首屏同时开 5 个区域（案卷文件树 + 大纲 + 源码 + PDF + AI/术语），无一主体；打开"审阅 / 版本历史 / AI"会**顶掉源码 Tab** 而不是伴随在右侧（违反 benchmark L9/L10/C15）；台账首页 4 个 KPI 卡里 3 个是 0，占据首屏最显眼位置。见 §3 W-01 / D-01。
3. **移动端没有达到 L15**：工作台 375 首屏 chrome ≈ 305px（37.6%），内容占比 62%（目标 ≥ 80%）；375 触控目标 < 44px 的控件在工作台占 19/23、台账占 21/27、递交页 15/18。见 §2.6。
4. **深色模式是"反色"而不是"设计"**：纸面恒白（正确）但周围壳 `--n9` 深底 + 绿色主按钮饱和度无变化，构建按钮在深色下是全站唯一高饱和块，PDF 构建被打断后出现"已取代 / 尚无 PDF 预览"状态而无恢复动作。见 §3 各卡"深色"。
5. **下一步（如无异议按此执行）**：W6 设计以本文 §4 Top-25 为输入，先出 3 张关键页（台账首页 / 工作台默认 / 移动工作台）的 HTML 高保真原型，再落 token → 组件 → 页面。

### 2.1 按钮 / Tab / 菜单项高度（实测：桌面 1440 亮色 62 页 2697 个采样；移动 375 亮色 60 页 1052 个）

### 2.2 圆角

| 圆角 | 桌面占比（2697） | 移动占比（1052） | 说明 |
|---|---|---|---|
| 4px | 76.7% | 68.5% | 一切按钮 / 输入 / 卡片 / 对话框 / 菜单 |
| 0px | 15.4% | 18.6% | 底部 Tab、表格行、文字链 |
| 9999（pill） | 6.6% | 9.8% | 筛选 chip、状态徽章、构建按钮 |
| 6px | 1.3% | 3.0% | KPI 卡 |
| 2px | 0.1% | — | 勾选框 |

> C2 要求"圆角随尺寸"（≤32 → 4，36–40 → 6）：实测 40px 的移动控件仍是 4px；36 的表单输入也是 4px。**全站只有一种圆角感**，卡片 / 对话框 / 按钮无层级差——这是"看起来像旧版"的第二大原因（Overleaf 卡片 8、按钮 4；Notion 6/8/12）。

### 2.4 灰阶与颜色

- 文本颜色只用了 **2 个中性阶**：`--n9` oklch(0.25) 正文 17597 节点、`--n7` oklch(0.441) 次要 12298 节点（桌面亮色合计 26 种文字色中这两种占 90%）；另有 `rgb(0,0,0)` 2142 节点（PDF textLayer / 版面纸面，属纸内，不算壳）。占位符 `--n6`、禁用态几乎不出现。
- 背景中性阶：`--n0` 白、`--n1` 0.97、`--n2` 0.934 三阶承担了 91% 的面；`--n3` 只作边框。**面与面之间最大明度差 0.066**——侧栏、顶栏、面板头、内容区几乎同色，这就是"没有区块感"的直接原因（Overleaf 编辑器侧栏用深色 `#1e253a`，飞书用 `#f5f6f7` 侧栏 + 白内容）。
- 品牌绿 `--green-600` 用于：主按钮、构建按钮、rail 激活、Tab 下划线、链接、选中行左条、KPI 图标底、AI 审阅按钮、协作者"协作"Tab、成员在线点、通知未读点、状态"已递交"点——**一色多义**，13 种语义。
- 非 token 色：`rgb(239,68,68)`（Tailwind `red-500`，48 处：头像、通知未读徽章、期限"剩 1 天"）、`rgb(255,255,255)`、看板列头随状态色——C26 ✗。
- 任意值 class：桌面 61 种 / 移动 41 种（`census.json › arbitrary`），尺寸类如 `size-[30px]`（121 处）、`h-[22px]`（56）、`h-[26px]`、`min-w-[91px]`、`text-[9.6px]`、`leading-[14px]`（925 处，状态栏/树）、`max-w-[11rem]`，说明尺寸阶没有被组件消费，仍在页面层手写。
