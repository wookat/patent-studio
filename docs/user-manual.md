# 知撰 使用手册

> 「知撰·AI 专利撰写与协同平台」（简称知撰；仓库与代码内的技术名为 Patent Studio）面向用户的功能全景说明。基于 develop@2ac001d 全功能实机走查（14 域逐面验证）编写。

## 1. 平台是什么

知撰是面向中国发明专利申请的**撰写与管理一体化工作台**：从建案、交底导入、三书（摘要/权利要求书/说明书）撰写、附图管理、协同审阅、期限与 OA 答复，到 DOCX/PDF/XML 递交产物导出——各环节在同一个工作区内完成。AI 以「案卷工程师」身份在场：可以对话、跑场景、提修订提案，也可以被 Codex / Claude Code / Devin 等外部 agent 通过 MCP 接入驱动。

核心原则：**修改可审、可回溯**。工作台内 AI 的改动以提案形式给出、待你确认才进入正文；多会话并发写有乐观并发保护；每次写入都会留下 git 版本与审计记录。知撰辅助撰写与审阅，不提供法律意见，不承诺受理或授权结果。

## 2. 五分钟上手

1. **登录**：账号密码登录（机构管理员可先开账号、邀成员）。
2. **建案**：台账右上「新建案卷」——填案号/名称/类型/客户等 6 字段；或直接「导入」拖入现有 docx。
3. **写稿**：打开案卷进入工作台——三书四视图（源码/结构/版面/PDF），块级编辑，插入章节/公式/表格/附图引用/权项引用。
4. **用 AI**：右栏 AI 面板——「场景」页签跑起草/查新/OA 答复等 s1–s10 场景；「对话」页签直接说「帮我查先行技术」「画一个系统架构图」。
5. **协同**：协同中心邀成员（编辑/查看/审阅角色）或发客户免登录审阅链。
6. **递交**：「递交」页四步走完，产出 DOCX 五书 / PDF / CNIPA XML 包。

## 3. 功能全景

### 3.1 台账（Dashboard）

- **视图**：表格 / 看板（按状态分列，折叠列）双视图；筛选、分组、排序、列显示全部可配且**按用户持久化**。
- **建案**：新建对话框 6 字段（案号/名称/类型/申请人/客户/备注等）；「导入」支持 Word 文档一键转案卷。
- **批量操作**：状态流转 / 标签 / 责任人 / 归档 / 移入回收站五动作批量条。
- **行内 ⋯ 菜单**：案件信息表单（全台账字段 + 7 个日期 + 优先权）、改状态、归档、删除。
- **回收站**：软删案卷可恢复或永久删除（两步确认）。
- **CSV 导出**：台账数据一键导出。

### 3.2 工作台 · 三书编辑

- **四视图**：源码（CodeMirror）/ 结构（块树）/ 版面（所见即所得）/ PDF 预览，任意组合分栏，拖拽调宽。
- **块级编辑**：双击进入块编辑；插入章节/小节/公式/上下标/表格/附图引用/权项引用 7 类。
- **术语表**：案件级术语管理、术语一致性检查、改名保序。
- **修订（CriticMarkup）**：{++增加++} / {~~删除~~} / {~~旧~>新~~} 标记流，逐条接受/拒绝，批量操作有两阶确认。
- **批注**：选文即批（@成员/客户）、回复线程、解决/删除；客户审阅批注带徽标区分。
- **全文搜索**：跨书检索，命中即跳到对应段（`?c=`/`?focus=`/`?dl=` 深链可直达）。
- **⌘K 命令面板**：案卷/面板/页面/动作模糊搜索，快捷键全列表可查。
- **公式**：KaTeX 渲染，内嵌公式双击可编辑。
- **自动保存 + 乐观并发**：多人/多页签编辑同一案卷时，写操作带版本校验，冲突不静默覆盖。

### 3.3 附图

- **图卡管理**：上传（png/svg/jpg/emf 等，≤50MB）、拖拽排序、宽度（≤17cm 合规钳制）、题注、摘要图指定、原地换图。
- **标号表**：案卷级部件标号（如「处理器 101」）跨图登记去重，绘制时可点选插入。
- **绘制管线**：`figs-src/*.mmd`（Mermaid 图源）为唯一真源——附图书「绘制」跳**整页画板**（Excalidraw）：左侧画布拖拽精调，右侧可收「源码」窗（防抖 400ms 单向刷画布），标号 chips 一键插入节点文本。
  - **契约**：画布调整只进导出 PNG，不回写 mmd（mmd 是版本化真源）。
  - **导出**：白底 4x≈300dpi PNG 直进附图节，题注/标号/DOCX/XML 自动继承。
  - **CNIPA 风格**：黑白线稿（roughness=0），直线直线，所见即递交所得。
  - **AI 协同**：对话里说「画一个 XX 架构图」→ agent 写 mmd → 你在画板精调 → 一键导出。
- **期限联动**：期限中心汇总全案期限；OA 轮次自动带发文日。

### 3.4 协同中心

- **成员**：角色四档（owner/editor/viewer/客户），邀请、移除、改角色；变更有通知。
- **分享链**：两档——登录协作链（平台内协同）与客户免登录审阅链（只读 PDF/版面 + 批注 + 确认定稿 + 可禁下载）。
- **访问记录**：谁在何时看了什么。
- **协同设置**：案级开关。
- **在线状态（presence）**：同案成员头像实时在线。
- **@提及**：批注/对话里 @成员 → 通知中心直达（深链跳到对应位置）。

### 3.5 AI 面板（案卷工程师）

四页签——**建议 / 对话 / 任务 / 场景**：

- **对话**：流式多轮，markdown 全渲染（代码高亮/数学式 KaTeX/表格/任务清单勾选框），支持拖附件（docx/pdf/txt/代码抽文本）。**工具循环**：模型可直接调平台 72 件工具——读面（查 AST/体检/查新/批注/期限等）直跑不打扰；写面（改文档/台账/期限/OA/分享链/提案/机构设置）**先弹确认卡**，你点「执行」才落；删除/覆盖类带「危险操作」徽标；机构成员变更走**二次确认**（stage=2）。任务会落成 audit.jsonl 审计行可回看。
- **建议**：AI 产出的 CriticMarkup 修订提案列表，逐条「接受/拒绝」——接受才进正文。
- **任务**：后台跑批（含 token 用量、耗时、取消）。
- **场景 s1–s10**：交底→三书、权项打磨、说明书展开、一致性体检、附图对齐、术语统一、OA 答复、s8 真实查新（PatSnap/OpenAlex/Crossref/arXiv 源可配）等场景化跑批，产出走提案制。
- **外发闸**：机构级 + 案级双层 AI 外发开关；模型路由（interactive/heavy/fallback）机构设置可见。
- **快捷动作**：选文后浮条——续写/润色/翻译/查新/提批注。

### 3.6 体检（Preflight / 诊断）

确定性规则引擎（非 AI）：结构完整性、权项支持性、术语统一、附图标号对齐、模糊用语、商标符号、§25 排除项等 30+ 条规则，筛 chips + 分组展示。命中条目可**内联「AI 修复」**（送 agent 出提案）。「跑一遍」出耗时/页数；构建缓存可清。

### 3.7 历史与版本

每案一个 git 版本库：自动快照 + 手动存点，版本命名、A↔B 任意两版 diff、恢复到任一历史版本（写库带 flock 互斥）。恢复结果会如实报「本就一致」。

### 3.8 期限与 OA

- **期限**：台账汇总 + 案内期限栏；新增/改期（带原因）/完成/撤销完成；深链 `?dl=<id>` 直达行。
- **OA 答复**：轮次管理（发文日/绝限自动算）、拆条工作集（审查意见逐条拆、本地确定性处理不送 AI）、要点稿编辑、延期/标已答复。

### 3.9 递交与导出

四步递交向导：申请信息（申请号等格式校验）→ 产物确认 → 导出。产物行：**DOCX 五书**（摘要/权项/说明书/附图说明/附图）、PDF、**CNIPA XML 包**（官式 DTD 校验过）、修订对照版、附图打包、manifest。缺必填项出红卡提示。

### 3.10 分享端（免登录审阅）

客户点开链接即见：PDF/版面只读视图、批注（可回）、「确认定稿」钮；链接可吊销、可禁下载。访问留痕。

### 3.11 移动端（375 壳）

底导航五件（大纲/审阅/更多…）、视图切换、批注移动路径、台账移动壳零横滚；触控密度自动适配（44px 命中区）。

### 3.12 机构管理与账户

- **机构**：成员表（角色/禁用）、标签模板库、审计日志（全动作可查可翻页）、AI 外发闸 + 模型路由 + 日 token 预算。
- **账户**：个人信息、改密（改完全局会话失效）、外观/偏好、PAT 个人令牌（供外部 agent 接入）。

## 4. 角色与权限矩阵

|---|---|---|---|---|---|---|
| 读三书/附图/批注 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓(只读) |
| 写正文/提案 | ✓ | ✓ | ✓ | ✗ | ✗ | ✗ |
| 批注/回复 | ✓ | ✓ | ✓ | ✓ | ✗ | ✓(审阅链) |
| 期限/OA 写 | ✓ | ✓ | ✓ | ✗ | ✗ | ✗ |
| 建案/删案/递交导出 | ✓ | ✓ | ✓(限) | ✗ | ✗ | ✗ |
| 成员/分享链管理 | ✓ | ✓ | ✗ | ✗ | ✗ | ✗ |
| 机构设置/成员管理 | ✓(机构超管) | ✗ | ✗ | ✗ | ✗ | ✗ |

## 5. AI 能力边界（诚实清单）

**能做**：对话内调 72 件工具（读全案/查新/体检/建案/台账期限 OA 写操作经确认卡/提案全套/场景跑批/图源生成/机构管理受限面）、markdown+附件多轮、计划闸（多步任务先出计划你批准）。

**不做**（指工作台内 AI）：不直写正文（提案制）、不碰凭据密码面外的凭据链由人确认、不联网发信操作外部系统（MCP client 反向接入是另通道）、s8 查新结果带数据源标注不编结论、外观产品线稿（AI 生图风格不可控，走外部工具导 PNG）。经 MCP 接入的外部 agent 写权限按其授权角色判定，详见 [mcp.md](mcp.md)。

**外部 agent 接入**：同一工具注册表经 MCP 暴露（stdio/HTTP），Codex / Claude Code / Devin 可连——`patent-studio-agent` skill 已发布；PAT 令牌 + ACL 权限同口径。

## 6. 数据与安全

- **案卷即文件树**：`projects/<pid>/` 下 docs/figs/figs-src/.studio 台账，全程可读可移植。
- **版本**：每案 git 库，写操作 flock 互斥、原子写（tmp+os.replace）。
- **审计**：案级 `audit.jsonl` + 机构级审计事件，chat 任务/工具调用/权限变更全留痕。
- **并发**：PUT 乐观并发（base_sha）、跨案竞态守卫、同案多页签覆盖告警。
- **隐私**：对话只存浏览器本地（换设备不同步）；案卷内容不进服务端会话表；PAT/密码不外发。

## 7. 常见问题

- **对话刷新就没了？** 已修——对话按案持久化在浏览器本地（尾 50 条）。
- **AI 写的为什么没直接进正文？** 提案制——「建议」页签或对话确认卡里接受才落。
- **画布改了源码没变？** 契约——mmd 是唯一真源，画布只影响导出 PNG；改图源走源码窗或让 AI 改。
- **附件/图片能给 AI 看吗？** 文档附件可以（docx/pdf/txt）；图片暂拒——当前模型网关不读图。
- **XML 递交验证过没？** 五书导出已过官方 DTD；CPC 客户端真机导入在验收中。
